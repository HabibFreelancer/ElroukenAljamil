Guide d'exécution et de test en local
Il y a 2 modes selon ce que tu veux faire.

Mode 1 — Infra Docker + microservices depuis Visual Studio (recommandé pour le dev)
C'est le mode le plus pratique : tu lances l'infra en Docker et les APIs depuis VS avec hot-reload.

Étape 1 — Lancer l'infrastructure

cd c:\Users\X280\source\repos\leboncoin

docker compose up sqlserver rabbitmq elasticsearch redis minio -d

Étape 2 — Lancer les microservices depuis Visual Studio

Dans VS, clic droit sur la solution → Set Startup Projects → Multiple startup projects → mettre en Start :

ElroukenAljamil.Identity.API → port 5002

ElroukenAljamil.Listings.API → port 5001

ElroukenAljamil.Messaging.API → port 5003

ElroukenAljamil.Media.API → port 5004

ElroukenAljamil.Search.API → port 5005

ElroukenAljamil.Notification.API → port 5006

ElroukenAljamil.ApiGateway → port 5000

Appuyer sur F5.

Flux de test de bout en bout
1. POST /api/auth/register   → créer un compte
2. POST /api/auth/login      → récupérer le JWT token
3. POST /api/listings        → créer une annonce (avec Bearer token)
   → RabbitMQ publie ListingPublishedEvent
   → Search.API consomme l'event → indexe dans Elasticsearch
4. GET  /api/search?q=voiture → rechercher dans Elasticsearch
5. GET  /api/search/suggest?q=voi → autocomplétion
